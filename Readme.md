# Stallings Foldings for Subgroups of Amalgams

A Python implementation of the generalized Stallings-folding algorithm for finitely generated subgroups of amalgams of finite groups, constructing finite labelled graphs representing reduced precovers.

The project implements the six-step construction described in Section 8 of:

> L. Markus-Epstein, *Stallings' Foldings and Subgroups of Amalgams of Finite Groups*.

The implementation works with finite groups represented by labelled Cayley graphs and constructs reduced precovers representing finitely generated subgroups of an amalgam.

## What this project does

The implementation provides labelled-graph operations required by the construction, including:

* labelled graph construction and traversal
* graph folding and vertex identification
* monochromatic component detection
* subgroup/stabilizer computations
* Cayley and relative Cayley graph constructions
* construction of reduced precovers for finitely generated subgroups

The main algorithm follows the six-step procedure from the paper.

## Mathematical setting

Given finite groups \(G_1\) and \(G_2\), together with an identified subgroup

$$
A \leq G_1,\qquad A \leq G_2,
$$

the program works with the amalgam

$$
G_1 *_A G_2
$$

and constructs a finite labelled graph representing a finitely generated subgroup.

The factors are represented explicitly by their Cayley graphs. This makes the implementation closely reflect the combinatorial construction in the paper.

## Example

A simple example using a finite dihedral group and a cyclic group:

```python
from stallings_amalgams import Graph, D12, C4

# With the cayley graph of D12 = < a,b | a^6 = 1, bab = a^{-1} > and C4 = < c | c^4 = 1 > already constructed in Stallings_fin_amalgams
# And A gluing elements b and c^2. Encoded by A = {6:2}:

A = {6:2}

    ["b"],
    ["a", "b", "a^-1"],
    ["a", "c", "a", "c", "a", "c"],

```
